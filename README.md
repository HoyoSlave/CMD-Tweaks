## About Module
**CMD Tweaks** is an advanced performance and system management module designed to dynamically optimize daily use and gaming experiences. It features deep system controls, resolution changers, graphics management, and automation scripts.

---

## Main Features

### 1. Home & Automation (`./loop.sh`)
* **Start/Stop `./loop.sh`:**<br>&nbsp;&nbsp;&nbsp;&nbsp;Starts or stops shell-ascend (auto adapts to daily or gaming use).
* **Auto Game Preload:**<br>&nbsp;&nbsp;&nbsp;&nbsp;Preload game assets into memory for faster loading and rendering.
* **Enable Don't Disturb:**<br>&nbsp;&nbsp;&nbsp;&nbsp;Mute incoming calls and notifications for an immersive experience.
* **Use Dalvik Compile:**<br>&nbsp;&nbsp;&nbsp;&nbsp;Running every 3 AM to improve performance and system efficiency.

### 2. System & Settings Profiles
* **System Profiles:**
  * *Performance:*<br>&nbsp;&nbsp;&nbsp;&nbsp;Favors performance (*Disable Thermal option* to unlimit performance while overheating).
  * *Balanced:*<br>&nbsp;&nbsp;&nbsp;&nbsp;Balances performance with energy usage.
  * *Power Saver:*<br>&nbsp;&nbsp;&nbsp;&nbsp;Saves energy while reducing performance (*Maximum Refresh Rate option* to unlimit 60Hz in power saver).
* **Multitasking Profiles:**<br>&nbsp;&nbsp;&nbsp;&nbsp;Control how apps can run in the background (*Higher* to *Lowest* memory usage).
* **Root & System Tweaks:**
  * **[root] Fast Charging:**<br>&nbsp;&nbsp;&nbsp;&nbsp;Disables thermal services automatically when charging.
  * **Disable Device Sensors:**<br>&nbsp;&nbsp;&nbsp;&nbsp;Disables gyroscope, camera, etc. to reduce CPU load.
  * **Disable Google Protect:**<br>&nbsp;&nbsp;&nbsp;&nbsp;Disables daily scanning and protection.
  * **Disable Google Services:**<br>&nbsp;&nbsp;&nbsp;&nbsp;Disables Google account, contacts, etc. to reduce memory usage.
  * **Disable Network Stats:**<br>&nbsp;&nbsp;&nbsp;&nbsp;Disables network statistics to increase download speed.
  * **Enable Data Saver & Doze Mode:**<br>&nbsp;&nbsp;&nbsp;&nbsp;Restricts background data and activity.
  * **KILL USER APPS:**<br>&nbsp;&nbsp;&nbsp;&nbsp;Force closes all user apps to free up memory.

### 3. Game & Graphics Management
* **Global Scale:**<br>&nbsp;&nbsp;&nbsp;&nbsp;Overall resolution changer for better performance or screen sensitivity.
* **Game Manager (A12+):**<br>&nbsp;&nbsp;&nbsp;&nbsp;Games resolution changer.
* **Renderer (Graphics Engine):**<br>&nbsp;&nbsp;&nbsp;&nbsp;Selects the rendering backend (Default, SkiaGL, SkiaVK).
* **Angle (OpenGL ES Driver):**<br>&nbsp;&nbsp;&nbsp;&nbsp;Translates OpenGL ES to Vulkan API.
* **Unreal Engine Configs:**<br>&nbsp;&nbsp;&nbsp;&nbsp;Adjust Unreal Engine graphics and recompile to fix rendering issues.
